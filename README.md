# Lincoln Cicala — Stats de Jogo

App Next.js (Vercel) para exibir estatísticas individuais de **Lincoln Cicala** (FC Cincinnati) durante um jogo.

Estrutura alinhada ao repositório do Hudson Cicala, com visual SGA (tema escuro, tipografia Source Sans 3 + Good Times).

## Desenvolvimento

```bash
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000).

## Dados

Edite `data/gameStats.json` para atualizar números e links de vídeo (`carries`, `finalThirdActions`).

## Deploy

Conecte o repositório na Vercel; o `vercel.json` já define o framework Next.js.
